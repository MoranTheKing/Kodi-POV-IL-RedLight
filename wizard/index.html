התקנת הסקינים

אם ניסית קודם והתוספים לא הופיעו — זו הסיבה.
script.fentastic.helper דורש את script.module.requests, שלא קיים בקודי נקי. בלעדיו ה-helper לא נכנס, ושני הסקינים דורשים אותו — אז כל השרשרת נופלת בשקט.
הפתרון: מאגר. התקנה אחת, השאר נפתר לבד.
  1. הוסף מקור:
    https://morantheking.github.io/Kodi-POV-IL-RedLight/wizard/
  2. Add-ons → Install from zip file → repository.povillab-1.0.0.zip
  3. Add-ons → Install from repository → POV IL Lab → Look and feel → Skin
  4. בחר FENtastic או NOX — קודי יוריד לבד את כל התלויות

אם התקנת קודם ידנית ונכשל — אפשר פשוט להתקין מהמאגר מעל, אין צורך לנקות.
